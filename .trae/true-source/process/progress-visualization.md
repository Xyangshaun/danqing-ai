# 进度可视化规范

> 本规范定义任务进度的可视化呈现方式，支持实时查看各任务的完成情况。
> 所有可视化均基于 Markdown 表格与 ASCII 字符，无需额外工具支持。

---

## 一、可视化层级

| 层级 | 文件 | 用途 | 更新频率 |
| --- | --- | --- | --- |
| L1 总览 | `registry/active-tasks.md` | 全部活动任务概览 | 每次状态变更 |
| L2 分组 | `registry/active-tasks.md` 按状态分组 | 按状态查看任务 | 每次状态变更 |
| L3 详情 | `tasks/TASK-XXXX-<slug>/plan.md` | 单任务步骤进度 | 每次步骤完成 |
| L4 历史 | `tasks/TASK-XXXX-<slug>/changelog.md` | 单任务变更历史 | 每次变更 |
| L5 归档 | `registry/completed-archive.md` | 已完成任务统计 | 任务归档时 |

## 二、状态徽章

### 2.1 标准徽章

| 状态 | 徽章 | 文本 | 适用场景 |
| --- | --- | --- | --- |
| 待启动 | ⚪ | `PENDING` | 已创建未开始 |
| 进行中 | 🔵 | `IN_PROGRESS` | 正在执行 |
| 已阻塞 | 🟡 | `BLOCKED` | 等待依赖或资源 |
| 待验收 | 🟣 | `REVIEW` | 完成等待验收 |
| 已完成 | 🟢 | `DONE` | 验收通过 |
| 已取消 | ⚫ | `CANCELLED` | 终止执行 |

### 2.2 优先级标记

| 优先级 | 标记 | 颜色暗示 |
| --- | --- | --- |
| P0 | 🔴 紧急 | 红 |
| P1 | 🟠 高 | 橙 |
| P2 | 🟡 中 | 黄 |
| P3 | 🟢 低 | 绿 |

## 三、进度条表示

### 3.1 百分比文本格式

```
进度：3/8 (37%)
```

- 分子：已完成步骤数
- 分母：总步骤数
- 百分比：四舍五入至整数

### 3.2 ASCII 进度条（10 格）

```
[███───────] 37%
[██████────] 60%
[██████████] 100%
```

生成规则：
- 总格数：10
- 实心格数 = round(百分比 / 10)
- 实心字符：`█`
- 空心字符：`─`

### 3.3 多任务并列进度

```
TASK-0001  [██████────] 60%  🔵 进行中
TASK-0002  [██─────────] 20%  🔵 进行中
TASK-0003  [───────────]  0%  ⚪ 待启动
TASK-0004  [██████████] 100%  🟢 已完成
TASK-0005  [█████─────] 50%  🟡 已阻塞
```

## 六、并行执行矩阵视图

```markdown
| 任务对 | 可并行 | 冲突资源 | 处理建议 |
| --- | --- | --- | --- |
| TASK-0001 × TASK-0002 | ✓ | 无 | 可并行 |
| TASK-0001 × TASK-0003 | ✗ | qa/06-verify.md (W) | TASK-0003 串行等待 |
| TASK-0002 × TASK-0004 | ✓ | 无 | 可并行 |
```

**可视化标记**：

- ✓ 绿色对勾：可并行
- ✗ 红色叉号：存在冲突
- ⚠️ 黄色警告：理论冲突但影响小

## 七、单任务步骤进度（plan.md）

```markdown
## 执行步骤

| # | 步骤描述 | 产出物 | 预计耗时 | 状态 | 完成时间 |
| --- | --- | --- | --- | --- | --- |
| 1 | 环境搭建 | docker-compose.yml | 1h | [x] | 08-04 14:00 |
| 2 | 数据库 schema 设计 | schema.prisma | 2h | [x] | 08-04 16:30 |
| 3 | API 接口实现 | controller.ts | 3h | [~] | — |
| 4 | 单元测试 | *.test.ts | 2h | [ ] | — |
| 5 | 集成测试 | 集成测试报告 | 1h | [ ] | — |

**当前进度**：2/5 (40%)
**预计剩余**：6h
```

**状态标记**：

- `[ ]` 未开始（白色）
- `[~]` 进行中（蓝色）
- `[x]` 已完成（绿色）
- `[!]` 阻塞（黄色）

## 十一、可视化更新规则

1. **状态变更**：立即更新 L1 总览与 L2 分组
2. **步骤完成**：立即更新 L3 详情，同步 L1 进度列
3. **冲突变更**：立即更新并行执行矩阵
4. **任务归档**：从 L1/L2 移除，追加到 L5 归档
5. **日常同步**：检查所有视图与实际状态一致
