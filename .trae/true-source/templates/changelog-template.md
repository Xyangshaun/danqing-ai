## 变更类型枚举

| 类型 | 含义 | 版本号变更 |
| --- | --- | --- |
| `created` | 任务创建 | v0.1.0 |
| `status` | 状态变更 | 次版本 +1 |
| `progress` | 进度更新 | 修订号 +1 |
| `scope` | 范围调整（目标/步骤变更） | 次版本 +1 |
| `resource` | 资源占用变更 | 修订号 +1 |
| `blocked` | 任务阻塞 | 次版本 +1 |
| `unblocked` | 阻塞解除 | 次版本 +1 |
| `completed` | 任务完成 | 主版本置 1 |
| `cancelled` | 任务取消 | 主版本置 1，标记 CANCELLED |

## 维护规则

1. **只追加，不修改**：已发布的变更记录不可修改（除非笔误，需新增修订记录说明）
2. **每次变更一条**：一次提交对应一条变更记录
3. **关联提交 SHA**：必须填写对应的 Git commit SHA，便于追溯
4. **状态变更必须记录**：任何状态字段变化都要追加记录
