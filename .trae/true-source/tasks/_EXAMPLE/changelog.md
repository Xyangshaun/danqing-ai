## 维护规则

1. **只追加,不修改**:已发布的变更记录不可修改(除非笔误,需新增修订记录说明)
2. **每次变更一条**:一次提交对应一条变更记录
3. **关联提交 SHA**:必须填写对应的 Git commit SHA,便于追溯
4. **状态变更必须记录**:任何状态字段变化都要追加记录
