# 交互骨架优化与品牌升级 - Product Requirement Document

## Overview
- **Summary**: 对丹青有AI（DQ AI）创作诊断系统进行交互骨架深度优化与品牌视觉升级。核心目标是重构功能导航体系、优化信息可达性、升级品牌标识（Logo），使整体交互更符合专业创作工具的使用习惯，用户能更便捷地获取所需信息与功能。
- **Purpose**: 解决当前三栏布局下功能切换路径长、信息层级不清晰、品牌标识辨识度不足等问题，提升专业创作工具的操作效率与品牌感知。
- **Target Users**: 艺术创作者、设计师、艺术教师、学生等使用AI创作诊断工具的专业人群

## Goals
- **G-1 交互骨架重构**：建立清晰的功能优先级导航体系，核心功能（AI诊断）触达路径 ≤ 1次点击
- **G-2 信息可达性提升**：关键数据（历史记录、成长趋势、待改进项）在工作台即可预览，减少页面跳转
- **G-3 功能联动优化**：相关功能之间建立快捷跳转与上下文关联，如从历史记录一键复用参数到新诊断
- **G-4 品牌标识升级**：Logo替换为英文/DQ缩写形式，提升品牌专业感与国际化视觉
- **G-5 顶部栏效率化**：优化Header区域信息密度与功能入口，使其成为全局操作枢纽而非仅展示区
- **G-6 快捷键体系增强**：完善键盘操作体系，覆盖核心操作场景，提升专业用户效率

## Non-Goals (Out of Scope)
- 不改变核心分析算法与数据模型
- 不引入新的功能模块（仅优化现有9个页面的交互）
- 不更换技术栈（保持React + TypeScript + Vite + Tailwind）
- 不做移动端深度适配优化（保持现有响应式基础）
- 不引入状态管理库（如zustand）—— 保持现有LocalStorage方案
- 不做深色模式全量适配（仅预留主题切换基础能力）

## Background & Context
- 项目已建立完整的三栏生态软件布局（Header + Sidebar + Main + StatusBar），具备命令面板、数字快捷键、Toast通知、ErrorBoundary等基础设施
- 当前存在9个功能页面，分为三大类：核心工具（诊断/素材/风格/嫁接/情绪）、数据追踪（历史/成长）、系统（设置）
- Logo当前为中文"丹青有AI" + 调色板图标，用户希望升级为英文/DQ缩写形式，提升品牌专业感
- 功能之间的联动较弱，如从历史记录查看详情后无法快速复用参数进行新诊断
- 工作台（首页）信息密度尚可但可进一步优化，使关键数据更前置

## Functional Requirements

### FR-1: Logo品牌升级
- 将顶部栏Logo从中文"丹青有AI"替换为英文品牌名（如 "DQ AI" 或 "DanQing AI"）+ 图形标识
- Logo图形标识融入算法艺术/生成美学元素（参考算法生成的几何形态）
- 支持悬停微交互（轻微动效）
- 响应式适配：移动端显示缩写Logo，桌面端显示完整Logo

### FR-2: 顶部栏（Header）交互增强
- 搜索/命令面板入口强化，支持输入时实时预览最近访问记录
- 面包屑导航增加点击回退层级能力
- 在线状态指示器增加下拉菜单，显示本地/云端模式切换入口
- 通知图标增加未读数量角标，点击展开通知列表（替代纯装饰性）
- 用户头像区域增加快速操作菜单（个人中心、切换账号、退出）

### FR-3: 侧边栏导航优先级优化
- 核心功能（AI诊断）提升为一级突出入口，采用差异化视觉样式
- 导航分组更清晰：创作工具 / 数据洞察 / 系统设置
- 增加"最近访问"快捷区域（折叠时隐藏，展开时显示）
- 创作类型快速入口增加状态指示（当前选中的艺术类型）

### FR-4: 工作台信息架构优化
- 顶部欢迎区增加"快速开始"卡片组（4个最常用功能一键进入）
- 数据概览卡片增加点击跳转能力（点击"待改进"直接跳转到历史记录筛选低分作品）
- 最近作品卡片增加快捷操作（查看详情、再次诊断、删除）
- 右侧栏优化：合并每日艺语 + 创作提醒 + 快捷链接，减少视觉噪音
- 增加"继续创作"区域：显示未完成的诊断任务（如有）

### FR-5: 功能间联动与快捷跳转
- 历史记录详情页增加"用相同参数重新诊断"按钮
- 素材库/风格库作品卡片增加"用于灵感嫁接"快捷操作
- 灵感嫁接结果页增加"保存到素材库"入口
- 情绪画布生成结果增加"应用到风格库"选项
- 成长曲线数据点点击可跳转到对应日期的历史记录

### FR-6: 命令面板增强
- 支持搜索最近访问的页面和功能
- 支持搜索历史记录中的作品
- 支持快速执行操作（如"切换到云端模式"、"清除缓存"）
- 增加分类标签筛选（全部 / 功能 / 作品 / 操作）

### FR-7: 快捷键体系完善
- 新增快捷键：N = 新建诊断、B = 折叠侧栏、/ = 聚焦搜索框
- 快捷键在设置页可查看完整列表
- 各页面内增加页面级快捷键提示（右下角小图标）

## Non-Functional Requirements
- **NFR-1 性能**：首屏加载时间保持 ≤ 1.5s，路由切换骨架屏过渡 ≤ 300ms
- **NFR-2 可用性**：核心功能从任意页面触达 ≤ 2次点击
- **NFR-3 可访问性**：所有交互元素支持键盘导航，焦点状态清晰可见
- **NFR-4 一致性**：所有新增交互遵循现有设计系统规范（颜色、字体、间距、阴影层级）
- **NFR-5 兼容性**：保持现有浏览器兼容范围，不引入新的破坏性依赖

## Constraints
- **Technical**: React 18 + TypeScript 5 + Vite 5 + Tailwind CSS 3 + React Router 6 + lucide-react + recharts
- **Business**: 不改变核心业务逻辑，仅优化交互层与视觉层
- **Dependencies**: 不引入新的第三方UI组件库（如shadcn/ui、MUI等），所有组件基于Tailwind自定义

## Assumptions
- 用户主要使用桌面端（≥ 1280px宽度），移动端为辅助使用场景
- 用户具备一定的数字创作工具使用经验，对专业软件交互模式有认知
- 现有LocalStorage数据存储方案在当前用户量级下足够使用
- TRAE IDE内置图片生成API稳定可用

## Acceptance Criteria

### AC-1: Logo品牌升级
- **Given**: 用户访问应用首页
- **When**: 查看顶部栏左侧Logo区域
- **Then**: 显示英文品牌名（DQ AI / DanQing AI）+ 图形标识，而非原中文"丹青有AI"
- **Verification**: `human-judgment`
- **Notes**: Logo需具有生成艺术/算法美学特征，悬停时有微动画

### AC-2: 核心功能一键可达
- **Given**: 用户在任意页面
- **When**: 需要发起新的AI诊断
- **Then**: 可通过侧栏顶部突出按钮、顶部栏搜索、快捷键N三种方式 ≤ 1步到达
- **Verification**: `human-judgment`

### AC-3: 工作台数据可交互
- **Given**: 用户在工作台首页
- **When**: 点击数据概览卡片中的"待改进"或"累计诊断"
- **Then**: 跳转到历史记录页面并自动应用对应筛选条件
- **Verification**: `programmatic`

### AC-4: 历史记录可复用参数
- **Given**: 用户在历史记录详情页
- **When**: 点击"用相同参数重新诊断"按钮
- **Then**: 跳转到AI诊断页并预填对应的艺术类型与图片
- **Verification**: `human-judgment`

### AC-5: 命令面板搜索增强
- **Given**: 用户打开命令面板（⌘K）
- **When**: 输入关键词
- **Then**: 搜索结果包含功能页面、最近访问、历史作品三类结果，分类清晰
- **Verification**: `human-judgment`

### AC-6: 快捷键覆盖核心操作
- **Given**: 用户在应用内
- **When**: 按下N键
- **Then**: 跳转到AI诊断页面（输入框等元素聚焦时不触发）
- **Verification**: `programmatic`

### AC-7: 顶部栏通知可交互
- **Given**: 用户在任意页面
- **When**: 点击顶部栏通知图标
- **Then**: 展开通知列表面板，显示最近通知（而非纯装饰）
- **Verification**: `human-judgment`

### AC-8: 整体交互一致性
- **Given**: 用户浏览所有页面
- **When**: 对比新旧交互
- **Then**: 所有新增交互与现有设计系统（颜色、间距、动效、阴影）保持一致
- **Verification**: `human-judgment`
