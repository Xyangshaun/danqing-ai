### 2.3 截图拍摄指南

**如何拍摄高质量的TRAE开发截图**：

1. **打开TRAE IDE**，定位到需要截图的Session对话
2. **调整窗口大小**：确保对话内容完整可见，建议宽度1200px以上
3. **展开关键对话**：点击展开包含核心代码或关键决策的对话卡片
4. **隐藏敏感信息**：如对话中包含API Key等敏感信息，请打码或截掉
5. **标注重点**：可用系统截图工具的标注功能，圈出关键内容
6. **保存为PNG**：确保图片清晰，文件大小控制在2MB以内

**截图内容要素检查清单**：
- [ ] 截图中包含TRAE对话界面（左侧对话列表 + 右侧内容区）
- [ ] 截图中包含关键对话内容（代码、解释、决策过程）
- [ ] 截图中能看到TRAE的回复（证明是TRAE辅助开发）
- [ ] 截图清晰可读，文字不模糊
- [ ] 截图中无敏感信息泄露（API Key、密码等）

**拍摄步骤**：
1. 使用Chrome浏览器，按F11进入全屏模式（或隐藏书签栏）
2. 访问产品页面，准备真实数据
3. 使用系统截图工具或浏览器开发者工具的截图功能
4. 确保截图中不包含：
   - 浏览器开发者工具（F12）
   - 浏览器插件图标
   - 个人敏感信息
   - "localhost" 或 "127.0.0.1" 地址（使用已部署的链接）
