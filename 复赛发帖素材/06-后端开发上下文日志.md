## 三、各文件职责与核心内容

### 3.1 server.js — 主服务入口

**路径**：`server/server.js`

**职责**：
- Express应用初始化
- 中间件：CORS、JSON解析、URL解析、请求日志
- 限流：每IP每分钟30次请求，定期清理过期记录
- 文件上传：multer磁盘存储，支持JPEG/PNG/WebP/BMP，最大10MB
- 7条API路由
- 全局错误处理（含multer文件大小超限处理）
- 404处理
- 环境变量端口 `process.env.PORT || 3001`

**7条API路由**：

| 方法 | 路径 | 功能 | 请求参数 | 返回格式 |
|------|------|------|---------|---------|
| GET | `/api/health` | 健康检查 | 无 | `{ success, message, version, uptime, timestamp }` |
| POST | `/api/analyze` | 图片分析(文件上传) | FormData: `image`(文件) + `artType` | `{ success, data: AnalysisResult }` |
| POST | `/api/analyze-url` | 图片分析(URL) | JSON: `{ url, artType }` | `{ success, data: AnalysisResult }` |
| GET | `/api/artworks/search` | 搜索艺术品 | Query: `q, page, pageSize` | `{ success, data[], total, page, pageSize, totalPages }` |
| GET | `/api/artworks/category/:category` | 按分类查询 | Path: `category`; Query: `page, pageSize` | `{ success, data[], total, page, pageSize, totalPages }` |
| GET | `/api/artworks/:id` | 艺术品详情 | Path: `id` | `{ success, data: ArtworkItem }` |
| GET | `/api/style-categories` | 风格分类配置 | 无 | `{ success, data: styleCategories }` |

**import依赖**：
```javascript
import { analyzeImage } from './analysis.js';
import { searchArtworks, getArtworkById, getArtworksByCategory, getStyleCategories } from './knowledgeBase.js';
```

### 3.2 analysis.js — 图像分析引擎

**路径**：`server/analysis.js`

**职责**：基于Jimp进行像素级图像分析，支持4种作品类型

**核心函数**：

| 函数 | 功能 |
|------|------|
| `analyzeImage(imagePath, artType)` | 主入口，返回完整分析结果 |
| `analyzePixels(pixels, width, height)` | 像素基础分析：亮度图、边缘图、色彩桶、暖冷比 |
| `generateHeatmap(pa)` | 生成20x20热力图 |
| `calculateFocusPoint(pa)` | 计算视觉重心（加权平均） |
| `calculateSymmetry(pa)` | 计算对称性（左右亮度对比） |
| `calculateEdgeDensity(pa)` | 计算边缘密度 |
| `calculateTextureComplexity(pa)` | 计算纹理复杂度 |
| `analyzePainting(pa)` | 绘画分析：构图+色彩+笔触技法 |
| `analyzeDesign(pa)` | 设计分析：视觉层次+排版+色彩应用 |
| `analyzeProduct(pa)` | 产品分析：形态+材质表现+功能表达 |
| `analyzeSculpture(pa)` | 雕塑分析：空间构成+形体语言+材料语言 |
| `analyzeOriginality(pa)` | 原创性分析（通用） |
| `generateFallbackAnalysis(artType)` | 分析失败时的回退数据 |
| `rgbToHsl(r,g,b)` | RGB转HSL |
| `getHueCategory(h)` | 色相分类 |
| `getColorName(r,g,b)` | 获取颜色中文名 |
| `getLuminance(p)` | 计算亮度 |
| `isWarmColor(r,g,b)` | 判断暖色 |

**4种作品类型分析维度**：

| 类型 | 维度1 | 维度2 | 维度3 |
|------|-------|-------|-------|
| painting | composition(构图) | color(色彩) | brushwork(笔触技法) |
| design | visualHierarchy(视觉层次) | typography(排版) | colorApplication(色彩应用) |
| product | form(形态) | materialExpression(材质表现) | functionExpression(功能表达) |
| sculpture | spatialComposition(空间构成) | bodyLanguage(形体语言) | materialLanguage(材料语言) |

**返回数据结构**：
```javascript
{
  success: true,
  data: {
    id: "analysis-{timestamp}-{random}",
    imageUrl: "",
    createdAt: "ISO时间",
    artType: "painting|design|product|sculpture",
    dimensions: {
      type: "painting",
      composition: { score, focusPoint, balance, guideline, whitespaceRatio, symmetry, suggestion, heatmapData },
      color: { score, warmRatio, coolRatio, contrast, saturation, richness, harmony, dominantColor, suggestion },
      brushwork: { score, textureLevel, strokeVariety, wetDryBalance, suggestion }
    },
    originality: { score, similarity, creativityLevel, suggestion },
    overallScore: 82
  }
}
```

**与前端对齐关系**：
- 后端 `analyzePainting(pa)` ↔ 前端 `analysisService.ts` 中的 `analyzePainting(pa)`
- 后端 `analyzeDesign(pa)` ↔ 前端 `analyzeDesign(pa)`
- 后端 `analyzeProduct(pa)` ↔ 前端 `analyzeProduct(pa)`
- 后端 `analyzeSculpture(pa)` ↔ 前端 `analyzeSculpture(pa)`
- 后端 `analyzeOriginality(pa)` ↔ 前端 `analyzeOriginality(pa)`
- 后端用Jimp读取像素，前端用Canvas读取像素，算法逻辑完全一致

### 3.3 knowledgeBase.js — 知识库查询模块

**路径**：`server/knowledgeBase.js`

**职责**：从 `./data/artworks.json` 加载99件艺术品数据，提供6个查询函数

**导出函数**：

| 函数 | 参数 | 返回 |
|------|------|------|
| `searchArtworks(query, page, pageSize)` | 关键词(匹配标题/艺术家/标签/描述，支持中英文) | `{ data[], total, page, pageSize, totalPages }` |
| `getArtworkById(id)` | 作品ID | `ArtworkItem \| null` |
| `getArtworksByCategory(category, page, pageSize)` | 分类(painting/design/product/sculpture等) | `{ data[], total, page, pageSize, totalPages }` |
| `getStyleCategories()` | 无 | `styleCategories` 配置对象 |
| `getArtworksByStyle(category, style)` | 分类+风格 | `ArtworkItem[]`（接受 `'全部'` 通配符） |
| `getArtworksByEra(category, era)` | 分类+时代 | `ArtworkItem[]`（接受 `'全部'` 通配符） |

**数据来源**：从 `src/services/artworksDatabase.ts` 提取的99件艺术品，每件包含：
```
id, title, titleEn, artist, artistEn, year, category, style, era, region, description, imageUrl, source, sourceUrl, tags, dimensions, medium
```

**styleCategories 配置**（4类）：
- painting: 12种风格 + 10个时代 + 10个主题
- design: 6种风格 + 4个时代 + 6个主题
- product: 5种风格 + 3个时代 + 6个主题
- sculpture: 5种风格 + 5个时代 + 5个主题

|------|------|

| `isBackendEnabled()` | 读取后端开关状态（localStorage `danqing_backend_enabled === 'true'`） |
| `setBackendEnabled(enabled)` | 设置后端开关 |
| `setBackendUrl(url)` | 设置后端地址 |
| `checkBackendHealth()` | 健康检查，返回 `Promise<boolean>` |
| `analyzeImageBackend(url, artType)` | 调用后端URL分析，返回 `Promise<AnalysisResult>` |
| `analyzeImageUpload(file, artType)` | 调用后端文件上传分析，返回 `Promise<AnalysisResult>` |
| `analyzeImageWithFallback(url, artType)` | 智能调用：优先后端，失败回退前端 |
| `searchArtworksAPI(query, page, pageSize)` | 知识库搜索 |
| `getArtworksByCategoryAPI(category, page, pageSize)` | 知识库分类查询 |
| `getArtworkByIdAPI(id)` | 知识库详情 |

**智能回退逻辑**：
```
analyzeImageWithFallback(url, artType)
  ├─ isBackendEnabled() = true
  │   ├─ analyzeImageBackend() 成功 → 返回后端结果
  │   └─ analyzeImageBackend() 失败 → console.warn → 回退前端
  │       └─ analyzeImage() 前端Canvas分析
  └─ isBackendEnabled() = false
      └─ analyzeImage() 前端Canvas分析
```

## 九、注意事项

1. **PowerShell环境**：不能用 `curl -s`，需用 `Invoke-RestMethod`
2. **文件上传测试**：后端会自动清理uploads目录中的临时文件
3. **前端开关**：默认后端模式关闭（`danqing_backend_enabled` 未设置），需在Settings页面或localStorage中手动开启
4. **Jimp版本**：使用 `jimp@0.22.12`，ES Module兼容
5. **数据一致性**：`server/data/artworks.json` 与 `src/services/artworksDatabase.ts` 数据源相同（99件），如需更新需同步两处
